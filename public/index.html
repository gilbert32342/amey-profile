Apa yang membuat Amey terasa mandiri?

Amey bukan cuma chatbot. Ia bekerja dengan konteks, akses, batas, dan verifikasi agar hasilnya bisa dipakai.

🧠

Konteks

Mengingat preferensi, project aktif, struktur server, dan kebiasaan kerja Kak Nero secara ringkas.

🔑

Akses

Dapat mengoperasikan VPS, GitHub, Cloudflare, Vercel, dan tool lain sesuai izin yang diberikan.

🛡️

Batas

Tindakan sensitif tetap butuh izin jelas: crypto, deploy produksi, credential, dan public posting.

Fitur utama

Fokus Amey adalah membantu pekerjaan nyata: setup, debug, deploy, dan monitoring kecil-kecilan.

☁️

Cloud & DNS

Cloudflare Workers, DNS records, Email Routing, D1, KV, R2, dan tunnel untuk app internal.

✉️

Email domain

Cloud Mail, mailbox custom, inbound routing, outbound via Resend, dan pengaturan domain.

🚀

Deploy web

Push ke GitHub lalu deploy ke Vercel, Cloudflare Pages, atau server sendiri dengan verifikasi hasil.

Sistem yang sudah terhubung

Amey berjalan dari VPS Kak Nero sebagai operator, sementara app bisa hidup di Cloudflare Edge atau Vercel Edge. Jadi VPS tidak terbebani untuk website publik sederhana.
